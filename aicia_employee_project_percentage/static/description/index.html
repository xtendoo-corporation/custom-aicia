AICIA - Reparto Analítico

Módulo que añade la sección Reparto en la ficha del empleado para asignar proyectos (cuentas analíticas) con porcentaje libre a cada empleado.

Dependencias

  • HR
  • Analytic

Modificaciones

  • Nuevo modelo aicia.employee.analytic.line con campos: empleado, proyecto (cuenta analítica) y porcentaje.
  • Sección REPARTO en la pestaña Nómina de la ficha del empleado con tabla editable de proyectos y porcentajes.
